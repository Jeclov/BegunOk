## Описание

"БегунОк" - это мобильное приложение для Android, разработанное для работы с трекером безопасности "БегунОк". Приложение предназначено для отслеживания местоположения пользователей (детей, пожилых людей и т.д.), обеспечения их безопасности и предоставления возможности связи с опекунами.  Приложение является основным интерфейсом для настройки, управления и анализа данных, полученных от сети трекеров "БегунОк".

## Основные функции

•   Подключение к устройству:
    *   Упрощенное подключение через NFC
    *   Подключение путем сканирования QR-кода
    *   Ручной поиск устройства в сети Bluetooth (в разработке)
•   Отображение местоположения на карте: Отображение текущего местоположения отслеживаемых устройств в режиме реального времени. (в разработке)
•   Настройка геозон: Установка границ безопасных зон и получение уведомлений при их нарушении.
•   Получение уведомлений: Уведомления о выходе из геозоны, нажатии кнопки вызова на трекере, а также другие системные уведомления.
•   Просмотр истории перемещений: Просмотр истории перемещений отслеживаемых устройств за определенный период времени. (в разработке)
•   Управление несколькими устройствами: Поддержка подключения и управления несколькими трекерами "БегунОк". (в бета релизе)
•   Сохранение файлов журнала: Сохранение истории взаимодействия с устройством для отладки и анализа.

## Технологии

•   Платформа: Android
•   Язык программирования: Kotlin
•   SDK: Android SDK 24
•   Связь с трекером: Bluetooth Low Energy (BLE)
•   База данных: Room 

## Установка

1.  Склонируйте репозиторий:
bash
  git clone (https://github.com/Jeclov/BegunOk/new/)
```
2. Откройте проект в Android Studio.
3. Установите необходимые зависимости (менеджеры пакетов (Gradle)).
4. Соберите и запустите приложение на Android-устройстве или эмуляторе.

▌Настройка

•  Для подключения к трекеру "БегунОк" убедитесь, что на устройстве включен Bluetooth.
•  Следуйте инструкциям в приложении для сопряжения с трекером.
•  Настройте геозоны и параметры уведомлений в соответствии с вашими потребностями.
